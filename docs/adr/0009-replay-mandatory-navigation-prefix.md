# 可续跑发现必须重放强制导航前缀

某些 IVR 在每个新的外呼中都会先要求隐私同意、语言选择或身份分流，之后才允许到达目标分支。即使这些节点在之前的外呼中已经探索过，续跑更深节点时仍必须在当前通话里重放对应的 DTMF/语音路径；跳过它们会使通话无法到达目标节点。强制导航前缀的重放不是重复探索，也不改变已完成节点的状态。

## Consequences

- 续跑任务从“探索前沿”继续，而不是简单跳过所有已访问节点。
- `dtmf_path` 或等价的通话导航信息必须区分完整导航路径与当前探索目标。
- 一次探索呼叫可以在通话内顺序执行多个强制导航前缀，不会因为按键数量增加呼叫预算。
- 只有为了探索另一个分支或更深目标而发起新的真实外呼时，才增加呼叫预算。
