# 实时音频中继作为独立本机进程运行

实时音频流具有持续连接、缓冲和供应商 WebSocket 生命周期，不适合放入 FastAPI 请求进程或热重载路径。项目决定将中继作为独立本机进程运行：FreeSWITCH 只连接 localhost 音频入口，中继负责腾讯实时 ASR 会话和文本事件，后端通过本机事件通道消费结果。中继不得向局域网暴露。

## Consequences

- 后端热重载或 API 重启不应直接破坏中继的音频会话。
- 中继需要自己的启动脚本、健康检查、日志和优雅关闭。
- 中继故障时必须触发安全挂断或回退到文件 ASR，不能继续盲目 DTMF。
- FreeSWITCH 模块运行时不持有腾讯云凭据。
- 中继使用 Python 3.12+ / asyncio 与 `websockets` 实现，复用后端运行环境。
