# 已确认的 1w2 路径允许定时 DTMF 兜底

运营商实时 ASR 在真实通话中多次没有把英文语言菜单送入决策链，即使文件 ASR
能够识别 `For tech support in English, press 2`。因此实时文本兜底无法生效。

项目决定只为已实测确认的 `1w2` 路径增加一个受控定时兜底：

- 仅当按键序列恰为 `1w2` 时启用。
- 根节点 `1` 仍必须由实时 `dtmf_ready` 驱动发送。
- 发送 `1` 后，第二段仍优先等待实时 `dtmf_ready`。
- 如果 16 秒内没有目标键事件，才发送一次 DTMF `2`。
- 其它路径、根节点和其它按键序列不允许定时兜底。
- 兜底使用独立审计日志和配置 `CALL_DTMF_FALLBACK_DELAY_MS`。

该兜底不替代正式实时发现；它只用于确认已知语言菜单并获取英文分支录音。
