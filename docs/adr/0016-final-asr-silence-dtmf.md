# DTMF 只在 final ASR 和静音窗口后触发

实时导航不再用固定时间猜测 IVR 是否播报完毕。项目决定：首版只有在腾讯实时 ASR 产生 final 文本、文本中明确出现目标按键或选项、且随后 800 ms 没有新语音时才发送 DTMF。没有发现目标键时至少等待 3 秒，允许腾讯把一个菜单拆成多个 final 句子；3–5 秒内没有新的 final 文本时按未知边界停止。未知菜单不得猜测按键。

## Consequences

- partial 文本只用于前端显示和人工边界预警，不直接触发 DTMF。
- 需要维护每个探索呼叫的静音计时器、目标按键和 ASR 会话状态。
- IVR 提示语较长或 ASR 分段异常时，宁可停止当前呼叫，也不能盲目按键。
- 文件 ASR 继续作为通话后的复核结果。
