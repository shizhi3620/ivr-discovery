# 仅完整非工作时间提示豁免“请稍等”

非工作时间 IVR 会播放：

```text
作为评估和培训客服人员，改进客服中心技术质量……请稍等
```

该完整句子属于自动播报，不应被判定为人工边界并立即挂断。除此之外，
“请稍等”“排队”“please hold”仍然保留人工风险，不能全局移除。

项目决定：

- 只有完整匹配上述非工作时间语句时才从人工判断中豁免。
- 如果同一文本还包含转人工、人工坐席、正在转接等其它关键词，仍判定为
  人工边界。
- 其它节点的“请稍等”“排队”和 “please hold” 保持原有严格判断。

人工边界仍包括：

- 转人工、人工坐席、人工客服
- 为您转接、正在转接、转接人工、接通人工
- representative、live agent
- transfer you to、connect you to an agent
