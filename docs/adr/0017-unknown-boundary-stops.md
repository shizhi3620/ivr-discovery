# 非明确 IVR 菜单一律按未知边界停止

实时转人工可能没有任何“转人工”等强关键词，真人坐席也可能直接以普通问候接起。项目决定采用保守策略：只有实时 ASR 明确给出菜单选项、按键提示或可验证的 IVR 结构时才继续导航；强关键词人工边界或无法确认的未知边界都必须立即停止 DTMF 并挂断。宁可漏掉一段流程，也不进入真人对话。

## Consequences

- partial/final ASR 同时用于强关键词检测和菜单确认。
- 未知边界节点不扩展子节点，并以安全挂断结束当前探索呼叫。
- 关键词漏检不会自动演变成与真人继续对话。
- 未验证或未知边界必须在报告中保留为未完成项，不能推断为叶子节点。
