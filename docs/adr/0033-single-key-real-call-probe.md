# 真实节点验证只允许发送一个确定性目标键

阶段 5 需要在真实电话上验证实时 ASR、强制前缀导航和 DTMF 注入，但在完整
发现流程尚未接入媒体流之前，不能让单次试验自由探索多个节点。

项目决定新增受控真实呼叫探针：

- 每次真实呼叫必须显式传入 `--confirm-real-call`
- 只监听一个实时 ASR 目标键
- 只有确定性 `dtmf_ready` 事件可以注入一个 DTMF 键
- 遇到人工边界、未知边界、实时 ASR 错误或超时立即结束呼叫
- 注入后停止实时决策，继续录音并等待文件 ASR 返回下一层菜单文本

该探针不替代正式发现状态机。正式发现仍必须先实现 Target、DiscoveryWindow
和 Run 的预算与门禁。
