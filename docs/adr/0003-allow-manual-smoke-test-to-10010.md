# 短号仅白名单允许 10010

上游 Android 网关只接受 10–15 位号码，无法拨打中国联通客服短号 `10010`。第一阶段需要该号码作为人工监督下的冒烟测试，因此本地补丁精确允许 `10010`，不开放通用短号。其他短号可能涉及紧急、政务、金融或企业内线，默认拒绝比放宽长度限制安全。

## Consequences

- 号码校验不能简单改成“5–15 位都允许”，必须保留显式白名单。
- `10010` 只用于人工监督下的冒烟测试，不进入批量发现。
- 该冒烟测试不是一次性的：每次单独发起都要求操作者在场并实时决定中止。截至 2026-09-22 已用于两项验证——音频桥接，以及 DTMF 注入（见 `docs/adr/0002` 的验证记录）。
- 若未来新增短号，需要同时改本地补丁白名单和本 ADR，不能图省事放宽长度校验。
