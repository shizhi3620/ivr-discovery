# 最终 IVR 报告必须覆盖全部发现窗口

同一授权目标可能在不同时间进入不同电话流程。`4006668800` 在 21:00 前进入人工坐席服务，21:00 后进入 IVR 自助服务，因此单次发现 session 不能代表完整流程。项目决定：最终双语优化报告只能在所有必需发现窗口完成后生成；未全覆盖的结果只能标记为草稿报告。这样可以避免把某一时段的人工路径误当成完整 IVR 结构。

## Considered Options

- 每个 session 独立生成最终报告：速度快，但会把单时段结果误标为完整。
- 允许部分覆盖但由人工判断：依赖操作者记忆，无法形成稳定门禁。
- 等待全部发现窗口完成：交付更慢，但语义和报告结论可靠。

## Consequences

- 报告门禁不能只检查单个 session 是否 `completed`，还必须检查该目标的全部必需发现窗口是否都有完成记录。
- 目标或 session 需要携带发现窗口元数据；跨 session 合并属于后续数据模型的一部分。
- 单窗口结果只能生成草稿报告，并明确列出尚未验证的时段路由。
