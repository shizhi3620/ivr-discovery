# 自主发现未知菜单前必须接入实时 ASR

文件 ASR 只能在通话结束后提供文本，无法在通话中判断 IVR 是否播放完毕、何时发送 DTMF，也无法在实时人工坐席接起时立即挂断。项目决定：在自主连续导航未知菜单或正式完整发现之前，必须接入实时 ASR；文件 ASR 保留用于录音审计、结果复核和实时链路故障回退。

## Consequences

- 当前固定时间 DTMF 只保留给已经人工校准的短前缀；未知菜单不得依靠固定时间连续导航。
- 实时 ASR 必须同时接入音频流、部分结果和最终结果，并驱动 DTMF 发送与人工边界终止。
- 前端 `live_transcript` 在实时链路完成后才是真正的流式文本。
- 实现实时链路之前，系统只允许进行受控的单节点或已知前缀侦察。
